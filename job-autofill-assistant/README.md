## 本地求职工作台（2026-11-08）

扩展设置页提供产品功能、我的简历、求职工作台、帮助中心与设置五个入口。模块开关随简历保存，关闭模块保留资料并停止参与填写。日期通过月历选择，可仅保存年月。

工具栏图标打开浏览器原生侧栏。资料速查跟随当前简历，可搜索资料并填入网页上选中的字段。在浏览器内置页和其他扩展的界面，可以用资料速查复制后粘贴。顶部和填写结果都可以打开岗位草稿，核对后由用户保存。

工作台提供表格、看板和仪表盘，支持面试轮次、筛选、归档及 CSV 导入导出。新增和编辑使用右侧抽屉。投递记录位于独立的 `yanyuSubmissionsV1` 存储键，并随完整 JSON 备份导出。旧记录中的待核实状态继续保留。备份默认排除 API Key。

更新后在浏览器扩展管理页重新加载本目录，并刷新扩展设置页及待填网页。不会自动提交网申或认定投递成功。
