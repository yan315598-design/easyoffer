
## 2026-11-08 页面与数据边界

`options/app-shell.js` 管理五页入口和旧章节链接，切换前等待简历及 AI 设置保存。产品页的图标、布局和文案随扩展本地加载。`date-controls.js` 为简历日期复用一个顶层月历弹层，选择具体日期、仅保存年月或选择语义值时才更新原始字段。目标网站的日期适配器单独回读控件。

模块配置按简历保存。编辑和备份读取完整资料，填写前由共享 schema 投影启用模块。实习与工作共用经历 ID 和数据数组，按类型筛选。缺少开关的旧简历保留有内容的模块。

`tracker.js` 的表格、看板和仪表盘共用 `yanyuSubmissionsV1` 及筛选条件。面试轮次由记录 schema v2 保存，阶段仍为「面试中」，历史同时记录轮次变更。工作台在 Web Lock 中比较存储版本后写入。CSV 通过 ID 识别冲突，并按公司与职位检测疑似重复。StorageManager 将投递记录纳入完整 JSON 备份和恢复。

## 浏览器原生侧栏

Manifest 声明 `sidePanel` 权限和 `side_panel.default_path`。后台通过 `setPanelBehavior` 把工具栏点击绑定到原生侧栏。原生入口配置失败时，工具栏可以走页内 Dock 回退。选区填入仍在招聘网页上框选，并短暂使用 Shadow DOM 内的经历选择面板。

`popup/sidebar.js` 通过 ContentReady 连接活动标签页，再用顶层文档 Port 接收字段目标和任务状态。侧栏与旧 Dock 共用 `profile-catalog.js`。侧栏在扩展上下文直接从已按模块过滤的简历生成目录，因此受保护页面也可搜索和复制资料。网页写入前校验标签页 URL 和字段身份，招聘网站切页或替换控件后需要重新选择。侧栏顶部和任务结果共用岗位提取逻辑，使用一次性会话键打开工作台抽屉，最终以用户保存为准。
