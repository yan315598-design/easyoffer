
## 2026-11-08 页面与数据边界

`options/app-shell.js` 管理五页入口和旧章节链接，切换前等待简历及 AI 设置保存。产品页的图标、布局和文案随扩展本地加载。`date-controls.js` 为简历日期复用一个顶层月历弹层，选择具体日期、仅保存年月或选择语义值时才更新原始字段。目标网站的日期适配器单独回读控件。

模块配置按简历保存。编辑和备份读取完整资料，填写前由共享 schema 投影启用模块。实习与工作共用经历 ID 和数据数组，按类型筛选。缺少开关的旧简历保留有内容的模块。

`tracker.js` 的表格、看板和仪表盘共用 `yanyuSubmissionsV1` 及筛选条件。面试轮次由记录 schema v2 保存，阶段仍为「面试中」，历史同时记录轮次变更。工作台在 Web Lock 中比较存储版本后写入。CSV 通过 ID 识别冲突，并按公司与职位检测疑似重复。StorageManager 将投递记录纳入完整 JSON 备份和恢复。

教育、实习、工作和项目经历在编辑时拥有独立草稿。速查、自动填写和备份使用已保存的简历。排序跟随条目 ID，实习与工作沿用同一份底层经历列表。

首页从工作台读取未归档记录，沿用阶段归一化和面试轮次。待办链接打开对应申请，阶段链接复用工作台筛选。首页按准备简历、填写并核对、提交后跟进组织操作，速查练习嵌入填写步骤。详细填写演示复用帮助中心的文章入口。无片段地址默认显示首页，侧栏编辑使用简历深链接。

## 浏览器原生侧栏

Manifest 声明 `sidePanel` 权限和 `side_panel.default_path`。后台通过 `setPanelBehavior` 把工具栏点击绑定到原生侧栏。支持 `sidePanel.open` 的浏览器在绑定失败时仍可直接打开侧栏。较旧的浏览器保留页内 Dock 入口。

原生侧栏连接期间，`panel-layout.js` 测量网页的主布局。固定宽度超过可用空间时，它为当前文档临时添加缩放样式，断开后移除。框选遮罩在网页顶层按视口坐标绘制，选中的字段引用留在内容脚本。原生侧栏凭本轮令牌和页面地址确认资料。

一键与增量填入由当前网页持有任务。侧栏接收进度和完成快照，重连后可恢复暂停、继续和取消操作。站点适配记录已处理控件，通用引擎接手余下字段。普通文本的撤销记录仅保存在当前文档内存中，撤销时校验控件仍保留插件写入的值。

`popup/sidebar.js` 通过 ContentReady 连接活动标签页，再用顶层文档 Port 接收字段目标和任务状态。重复行同时提供身份字段以排序候选。速查支持按目标字段推荐、跨字段组合搜索和手动展开记录。停用模块可查看及复制。整条预览将当前页面、目标控件、行容器和候选字段绑定到一次性令牌，确认后逐字段重新核对。侧栏顶部和任务结果共用岗位提取逻辑，使用一次性会话键打开工作台抽屉，最终以用户保存为准。

## 通用多条填写和本地备份

北森适配器在当前表单分组内匹配教育、项目、家属等记录。网页重建控件后，填写结果按分组、记录身份和字段重新回读。自动选择文件限于用途明确且为空的独立附件字段，简历解析入口由用户操作，避免网站导入流程覆盖已填内容。

`structure.js` 根据分区标题、字段语义和重复容器绑定条目。已有行优先按身份字段匹配，空行按简历顺序绑定。添加按钮每次只点击一个，出现可确认的空白行后才继续。日期、选择器和地区控件由 `control-adapters.js` 与组件交互函数处理。既有表单组件保留各自的兼容入口。

`storage.js` 用同一份版本化 JSON 导出完整或部分资料，附件引用和内容一起核对。导入按 ID 合并。用户授权的目录句柄保存在扩展 IndexedDB，由后台在资料变动后写入带时间的独立快照，并回读文件确认。扩展安装目录和备份目录分别管理，快照始终省略 API Key。
