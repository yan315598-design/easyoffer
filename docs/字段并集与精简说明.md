# 字段并集与精简说明

本次字段整理来自 OfferLink「我的简历」实际页面、塔塔网申「我的简历」实际页面，以及本插件现有 detector / 扩展填写 / 选区填写链路。目标是保留真实可用的字段，不以“字段越多越好”为目标。

## 原则

1. **已有可填写字段继续保留**，包括原有基础信息、教育、工作、项目、奖项、证书、家庭、论文、专利、开源与问答。
2. **同义字段只保留一个录入入口**。月/年薪、多城市、年龄、合并职责等用现有字段或派生逻辑完成。
3. **低频不等于无用**。国企、银行、北森等表单使用的字段进入“高级字段”，而不是直接删除。
4. **旧数据不物理删除**。隐藏入口只影响编辑页展示；旧键仍参与存储、导入导出及已有的兼容回退。
5. 新字段必须接入 schema、存储、编辑、AI 解析及填写/选区链路，避免只能保存不能使用。

## 高频主表单

| 模块 | 主表单保留 |
|---|---|
| 基础信息 | 姓名、姓/名、手机、邮箱、性别、出生日期、证件号、政治面貌、民族、籍贯、毕业时间、婚姻、现居城市、紧急联系人、地址、社交主页 |
| 求职意向 | 期望职位、期望行业、期望城市、期望薪资、当前薪资、到岗时间、内推码、招聘渠道、出差意愿 |
| 教育 | 学校、学院、专业、学历、培养方式、院校层次、GPA、排名、起止时间、课程、在校说明 |
| 工作/实习 | 公司、部门、职位、工作性质、城市、起止时间、职责、成果 |
| 项目 | 名称、角色、类型、技术栈、起止时间、链接、描述、职责、成果 |
| 奖项 | 名称、级别、获奖时间 |
| 证书 | 名称、编号、机构、取得日期、有效期、等级、描述 |
| 技能与文案 | 技能标签、自我介绍、HR 打招呼语 |

## 隐藏入口但保留兼容

| 旧字段 | 唯一推荐来源 / 处理方式 |
|---|---|
| `basicInfo.honor` | `awards[]`；旧值仍可回退 |
| `basicInfo.specialSkills` | `skills[]`；旧值仍可回退 |
| `basicInfo.jobSources` | `jobIntention.recruitSource`；旧值仍可回退 |
| `foreignCitizenship` / `relativesEmployed` | 敏感原题进入个人声明与人工确认流程 |
| `personalPromise` | 承诺、签名由本人操作，不作为普通文本录入 |
| `location` / `politicalJoinDate` / 旧文件键 | 仅作历史兼容，不增加第二套入口 |

## 可选模块与语义复用

| 竞品能力 | 本插件实现 |
|---|---|
| 在校职务 / 干部任职 | 新增可选 `campusPositions[]`：组织、职务、干部级别、起止时间、描述 |
| 培训经历 | 新增可选 `trainings[]`：培训名称、机构、起止时间、内容 |
| 语言能力证书 | 新增可选 `languageCertificates[]`：语言/考试名称（如 CET-6/IELTS）、等级/水平、成绩、取得日期、掌握程度、听说能力、读写能力；作为 `languageSkills`（四六级/雅思/托福/其他外语）之外的可选高级补充，不替代旧字段 |
| 高中教育 | 复用 `education[]`，学历选择“高中” |
| 校园活动 / 实践活动 | 复用 `projects[]`，项目类型选择“校园活动”或“社会实践” |
| 计算机技能 | 复用技能标签与编程语言问答 |
| AI 工具应用 | 复用 `commonAnswers.aiTools` |
| 其他外语 | 复用 `languageSkills.otherLanguages` |
| 多城市、月/年薪 | 复用 `expectedCity`、`expectedSalary` 与薪资周期/单位 |
| 职责及业绩合并框 | 填写时由工作职责与成果派生，不重复录入 |
| 年龄、作品集链接集合 | 由出生日期、社交/项目链接派生，不落库 |

## 填写一致性修正

- 选区字段化在保留原有规则优先级的同时纳入新增字段，不再只取一小部分旧字段。
- 通用扩展映射从共享 schema 自动生成精确 label 映射，别名仍显式维护。
- 奖项级别为空时不虚构“校级”。
- 语言能力证书仅在存在对应语言/考试条目时填写；无对应语言条目时不猜测或虚构取得日期与成绩。
- 资料速查中的“姓氏/名字”与 `lastName/firstName` 对齐。
- 完整度中的 `hometown` 统一显示为“籍贯”，与独立“生源地”区分。
